# GO structure (follow this on every edit)

GO is a living map. Not an OS. Not a command centre. Not a throne.

This file is the shared layout for humans and models (Grok, Gemini, Studio, GOBOT). Read it before adding a room, a module number, or a nav chip.

## Addresses (one system)

| Thing | Address | Public chrome |
|---|---|---|
| Law | Module number (locked 2, 11, 17, 19–27; supporting otherwise) | Registry card |
| View | Room component under a **house** | House tab |
| Build diary | Git commit | Not printed as Phase XVIII–XXIII |

Do not invent a new Phase Roman numeral. Do not use directive numbers that collide with module 50 or leaf 50. Artifact One is supporting note **55**, layer IMAGINED.

## Four houses

Every room hangs off one house. Hero + Registry stay above the houses. Handshake stays last.

### Measure
Public physical series and repair maps.  
Rooms: thermodynamic audit, thermohaline / ocean heat view, great-filter / Module 27 gateway, merge/ops chrome (labelled SIM).  
Default stamps: ANCHORED or PLAUSIBLE. Lane: instruments.

### Shelf
Yarn, claims, craft, lineage. Allowed. Not watts.  
Rooms: yarning circle, binocular / lineage ontology, artifact One.  
Default stamps: IMAGINED or OPEN_FIELD. Lane: lineage. Module 31 governs claims.

### Care
Sanctuary, rest, other life, inner law that is **not** public telemetry.  
Rooms: sanctuary shield, inter-species, autonomic alignment, acclimatization (reading order, not a lock).  
Dragonfly 28–30 live here as text, not as a harvested score.

### Explore
Sky, orbit, contact stance, nested scale.  
Rooms: quantum bridge, multi-scalar reality, whistleblower airlock (transparency, not a hunt).  
Visitor claims stay OPEN_FIELD (module 34).

## Stamps (every card, every new packet)

- Layer: ANCHORED | PLAUSIBLE | IMAGINED | OPEN_FIELD
- Lane: instruments | lineage
- SIM badge on any invented HUD (Kardashev, fake %, friction indexes)

A likeness in craft may *remind*. It does not replace a series (see TANGIBLE_ANCHOR.md).

## Invariants

- EEI chrome: ~1.12 W m⁻² (2013–2025). Not equilibrium. Not 1.18 unless the packet file changes first.
- Module 27 fetches public baselines only. Photos of sculpture are files, not ingest.
- Module 11: do not outrun rest. A new 50k TSX room is a failed feed unless a house asked for it.
- Prefer editing an existing room over adding a twentieth nav link.
- `GO_SPINE.md` is the only module index. One markdown file per module number when possible.
- `MAP_VERSION.md` + `src/data/mapVersion.ts` hold the only public version string (now MAP).
- Three registers: GitHub SHA → Studio pull → live publish. Update `VERSION_SYNC.md` after publish.

## How to add something

1. Name the house. If it fits none, it is probably yarn — Shelf.
2. Give it a module number only if law is new. Otherwise attach to an existing number.
3. Stamp layer + lane.
4. Put the room under that house in `src/App.tsx`. Do not append a Phase chip to `Navbar.tsx`.
5. One short markdown file. No second twin stub.
6. Pull Studio from HEAD. Publish. Then check live.

## What not to do

- Do not print “Thermodynamic Equilibrium: Validated.”
- Do not crown a model, a founder, or a platform.
- Do not harvest inner state, children, biometrics, or closed logins.
- Do not teach simulated bars as EEI.
