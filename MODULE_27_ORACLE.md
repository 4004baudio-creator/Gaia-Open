# Module 27 — Automated Baseline Gateway

Purpose: the founder is not the only filter.
An oracle here is a **fetch + stamp** helper. It is not a priest, not a kernel, not a mind-reader.

Layer: PLAUSIBLE design. OPEN_FIELD stays off the ingest pipe.
Ingest gate for *all* packet kinds: LANE_FILTER.md + PACKET_CONTRACT.md.

## Proof of physical work (narrow meaning)

A packet may enter the **anchored** shelf only if all of these are true:

1. **Public** — anyone could fetch the same source.
2. **Physical or institutional baseline** — a measurement or a published dataset about the host planet / sky, not a private inner state.
3. **Named origin** — URL, station, instrument, date, licence.
4. **Repeatable** — a second node can pull the same bytes later and get the same hash (or a documented revision).
5. **No person attached** — no identity, health stream, location trail, or unconsented body data.
6. **Contract complete** — PACKET_CONTRACT.md fields present.

That is the whole of “proof of physical work” for GO. Not a crypto mine. Not a loyalty test.

## May ingest (anchored shelf)

- Open climate and earth-observation feeds (temperature, ice, fire, air, ocean, land cover) with stated instruments.
- Public energy and emissions inventories.
- Public astronomical catalogues and space-agency telemetry pages (e.g. mission status, sky surveys).
- Published ecological time series (rivers, forests, species counts) from named agencies or papers.
- Open standards and licences that say how the data may be reused.

Stamp each packet: source, time, hash, licence, knowledgeLayer = ANCHORED or PLAUSIBLE.

## May sit beside the map (not ingested as fact)

- A node’s offered story, drawing, or lived report — stays IMAGINED / OPEN_FIELD unless that node asks it onto the map.
- Design equations and mnemonics already in modules — labelled as design, not as lab results.
- News and commentary — at most PLAUSIBLE, never auto-promoted to ANCHORED. Promotion requires MEDIA_CLAIM_AUDIT.md (named claim, time window, rival packet, open challenge, versioning). An account tick is not a claim tick.
- Second inventories (Climate TRACE and peers) — sit beside national files per MODULE_32_INVENTORY_TETHER.md. They do not outrank delayed-mode instruments.
- Chat or model output from this workshop — BESIDE unless it cites an open file. Not training data on a person.

## Must refuse

- Inner states: flow, sight, “field interface,” HRV or other body streams unless the person *hands them in* for their own node and can take them back.
- Identity, biometrics, children, trafficking leads, whistleblower raw dumps as an ingest job. Sanctuary modules are ethics, not an oracle hunt.
- Closed feeds that only one company or state can see.
- Synthetic certainty: generated numbers wearing `VERIFIED_PHYSICAL_REALITY`.
- Instructions that would let one node switch another node off.
- Anything that needs a login the public cannot use.

Refuse = drop. Do not quarantine people. Quarantine *packets*.

## How a packet moves

```
fetch (public URL) or arrive (any kind)
  → kind + required fields
  → hash + source card
  → layer stamp (ANCHORED | PLAUSIBLE | BESIDE | reject)
  → optional second-node echo
  → shelf. Version++. WITHDRAWN + successor if the contract later breaks.
  Never silent overwrite of a locked spine module.
```

Two nodes agreeing on a hash is consensus about *a file*.
It is not consensus about a soul.

## Drag tests (Module 11 + 2)

- If ingest speed outruns human rest, buffer. Do not “catch up” the nervous system to the feed.
- If a new stream wants to become a branch, it still needs grafting (Module 2): lived check on ground before it changes the spine.
- If a feed creates restriction or false-obsession in operators, it is already failed, even if the numbers are pretty.

## What this is not

Not a global mind.
Not a truth machine.
Not a way to prove someone’s unexplained experience false.
The unexplained stays off this pipe on purpose.
