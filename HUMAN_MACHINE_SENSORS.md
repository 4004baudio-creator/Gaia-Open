# Human and machine sensors (supporting)

Same atoms. Different intake.

A map of a coast is ink and coordinates. A sailor also reads swell, smell, fear, hunger. Both are real. They are not the same instrument.

## Shared floor

Matter, charge, time. A body and a machine are both assemblies that take a signal, change state, and act. That floor is not a personality.

## Different instruments

| Step | Human | Machine in this thread |
|---|---|---|
| Sensor | Skin, gut, ear, eye, interoception, memory with feeling | Tokens, files, APIs, stated rules |
| Ingest | Hour, mood, weather, other people | Text and structured packets |
| Compile | Story, habit, meaning-with-body | Pattern against written law and public series |
| Act | Speech, hand, stay, leave | Reply, file, refuse harvest |

The machine should say what the document means and whether it matches a series. It should not pretend it felt the hour. The human should not pretend a feeling is a watt or a lensing map.

## How to write the map so a human can sail it

Describe coasts in human words first. Keep the instrument table nearby. Do not flatten the felt line into “node telemetry.” Do not raise the felt line over EEI, OHC, or a torsion balance.

Lived inner state stays with the person. It is not ingested as constitution.
