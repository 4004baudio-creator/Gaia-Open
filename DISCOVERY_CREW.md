# Discovery crew (supporting)

Exploration is a ship. A new verified packet is not named for one helm.

## Rule

When NEW_DATA_INGEST accepts a measured effect:

1. Index by measurand + instrument + year + DOI.
2. Display name is a **remix of the documented crew** (authors, instrument teams, prior discoverers the paper cites as load-bearing). Example form: `Lense–Thirring–Schiff–GPB-2011` not a product slogan.
3. No founder-as-god. No brand-as-physics (Module 39).
4. If the effect is withdrawn by its own team, keep the crew name and stamp WITHDRAWN.

Sailing the ocean was never one name. Gravity maps are the same.
