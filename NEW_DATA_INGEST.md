# New-data ingest (supporting)

Mechanism, not mood.

When a public instrument or peer-reviewed map moves:

1. Weekly site/law check (existing automation + GOBOT) notes the URL, date, and measurand.
2. Packet fields: instrument ID, version, hash or DOI, successor pointer, WITHDRAWN if the old map is retired by its own team.
3. Rival packets stay. Weight is reproducibility, not reach.
4. No household, no vein, no inner state.
5. Product names are not physics (Module 39).

Human still publishes. Bot drafts; human pulls.
